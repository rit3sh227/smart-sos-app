CAR ACCIDENT ALERT - native Android app (Kotlin)

OPTION A - Android Studio
  1. File > Open > select this folder, wait for Gradle sync.
  2. Build > Build Bundle(s)/APK(s) > Build APK(s).
  3. APK: app/build/outputs/apk/debug/app-debug.apk

OPTION B - no install, build in the cloud (free GitHub account)
  1. Create a new GitHub repository and upload ALL files in this folder (keep the .github folder).
  2. Open the repository's Actions tab > "Build APK" > wait ~3-5 minutes.
  3. Open the finished run and download "CarAccidentAlert-apk" (contains app-debug.apk).

Then: copy the APK to the phone, install it, allow notifications, type the PC's IP
address (ipconfig) and tap Save & Connect.
